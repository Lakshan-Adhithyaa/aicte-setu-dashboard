# AICTE Setu prototype

Dashboard-first prototype for AICTE approval workflow and post-approval compliance monitoring.

## Run locally

```bash
npm install
npm run dev
```

The role selector in the top-right previews Institution, Regional officer, Bureau officer, Committee member, Competent authority, and Administrator workspaces. Each role changes its navigation, metrics, queue, risk radar, and activity feed. The AI Setu bubble and product tour are available from every workspace.

This prototype uses synthetic demo records. AI Setu is intentionally presented as an evidence assistant: it can summarise, explain and prepare suggestions, but it does not replace authorised scrutiny, verification, or statutory decisions.
